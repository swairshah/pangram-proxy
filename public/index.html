How it works

1

Ask

POST your text to /detect. The server replies 402 Payment Required with signed payment requirements.

2

Pay

Your agent signs a USDC authorization (Circle Gateway, gas-free) and retries the same request.

3

Know

Payment settles, Pangram analyzes the text, and you get the verdict with per-window confidence scores.

Try it

# Free: get the exact price for your text
curl -X POST https://pangram.exe.xyz/quote \
  -H 'content-type: application/json' \
  -d '{"text":"...your text..."}'

# Paid: detect, using the Circle CLI agent wallet
circle services pay https://pangram.exe.xyz/detect -X POST \
  --address <your-wallet> --chain BASE \
  --data '{"text":"...your text..."}' --output json
